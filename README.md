Developed and compared two distinct deep learning models for the detection of Alzheimer’s Disease (AD) using MRI scans. The first model is a custom-built Convolutional Neural Network (CNN) architecture optimized for smaller datasets, achieving high accuracy and efficiency in classifying the stages of AD. The second model leverages the YOLO (You Only Look Once) algorithm, traditionally used in object detection, to evaluate its performance on the same MRI dataset. The comparative analysis highlights the strengths and limitations of both models. While AD-Net excels in precision, recall, and overall accuracy, YOLO's results (low accuracy with 20 epochs) demonstrate potential for improvement with further training. The study focuses on key metrics such as accuracy, F1-score, AUC, and loss to determine the optimal approach for automating early AD diagnosis using medical imaging.
